# Controles y atajos

Pulsa <kbd>?</kbd> en la app para ver un resumen.

## Teclado

| Tecla | Acción |
| --- | --- |
| <kbd>Espacio</kbd> | Pausa / continuar |
| <kbd>S</kbd> | Avanzar un paso de simulación (pausa si estaba en marcha) |
| <kbd>N</kbd> | Reiniciar las posiciones (mismas reglas) |
| <kbd>R</kbd> | Matriz aleatoria (la de la pestaña activa del editor: atracción, radio o conversión) |
| <kbd>M</kbd> | Mutar: pequeña variación aleatoria de la matriz de la pestaña activa |
| <kbd>B</kbd> | Nueva semilla y reiniciar |
| <kbd>1</kbd> – <kbd>9</kbd> | Cargar los presets 1 a 9 (los 10–12 están en el desplegable) |
| <kbd>T</kbd> | Activar / desactivar estelas |
| <kbd>P</kbd> | Captura PNG |
| <kbd>F</kbd> | Pantalla completa |
| <kbd>H</kbd> | Ocultar / mostrar la interfaz |
| <kbd>?</kbd> | Ayuda |
| <kbd>Esc</kbd> | Cerrar la ayuda |

## Ratón

| Gesto | Acción |
| --- | --- |
| Clic izquierdo + arrastrar | Atraer partículas hacia el cursor |
| <kbd>Shift</kbd> + clic | Repeler partículas |
| Clic derecho + arrastrar, o <kbd>Alt</kbd> + arrastrar | Desplazar la cámara |
| Rueda | Zoom hacia el cursor |
| Doble clic | Encuadrar el mundo entero |

El radio y la fuerza del "pincel" se ajustan en el panel, carpeta **Ratón**
(`mouse.radius`, `mouse.strength`).

## Pantalla táctil

| Gesto | Acción |
| --- | --- |
| 1 dedo | Atraer partículas |
| 2 dedos | Desplazar |
| Pellizcar | Zoom |

## Editor de matrices

| Gesto | Acción |
| --- | --- |
| Arrastrar ↕ sobre una celda | Ajustar el valor |
| Rueda sobre una celda | Paso fino |
| Clic derecho | Valor neutro (0 en atracción y conversión, 1 en radio) |
| Doble clic | Valor aleatorio |
| <kbd>Shift</kbd> + cualquiera de los anteriores | Editar a la vez (a,b) y (b,a): mantiene la simetría |

## Enlaces

| URL | Efecto |
| --- | --- |
| `…/#preset=5` | Abre directamente el preset 5 (de 1 a 12) |
| `…/#c=…` | Restaura un mundo guardado con *Copiar enlace compartible* |
| `…/?cpu` | Fuerza el modo CPU |
